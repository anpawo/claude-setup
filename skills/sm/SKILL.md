name: sm
description: "Summarize an answer as briefly as possible. Use when the user invokes /sm or $sm, or asks for the sm summary."
---

Typed alone, or naming an earlier answer: rewrite your previous message (or that answer) as short as it can be, adding nothing new.

Typed inside a message that asks something new: answer that message, in this same short shape, not the previous one.

The shape: one first line (what it says), at most 3 bullets of what the user must know or decide, one last line (the next action). Drop the detail, the proofs and the context. Keep every link, figure or name the user needs to act.
